# برنامه پارکینگ

یک صفحه موبایل‌فرست برای نمایش رزروهای پارکینگ‌های ۱۹، ۲۰ و ۲۱.

داده‌ها از فایل اکسل `برنامه پارکینگ-19-20-21.xlsx` استخراج شده و داخل `script.js` قرار گرفته‌اند، بنابراین سایت روی GitHub Pages بدون سرور اجرا می‌شود.

## به‌روزرسانی داده‌ها

اگر فایل اکسل تغییر کرد، باید دوباره داده‌ها را به `script.js` تبدیل کنیم و تغییرات را push کنیم.
